# Модели нейросетей в архиве прошивки

Файлы поставляются вместе с кодом, чтобы робот не зависел от интернета
(setup.py копирует их в /home/pi/models/, если там их ещё нет; с v1.6.12
каталог models/ ставится и веб-обновлением — OTA-обновление прошивки больше
не теряет модели). Суммарно ~20 МБ на диске и ~50 МБ ОЗУ при инференсе обеих
моделей — рассчитано на свободные ~500 МБ RAM робота (стек ~250/800 МБ).

* `yolov5n-seg.onnx` — **YOLO Mask**: сегментация (маски объектов), экспорт
  из официальных весов v7.0 (`yolov5n-seg.pt`) оригинальным экспортёром
  yolov5: opset 12, simplify, без динамических осей, вход 320x320
  (v1.6.12: реэкспорт с 640 — в ~3.5 раза быстрее и в ~3 раза меньше буферов
  cv2.dnn: пик RSS 34 МБ против 110 МБ), 7.7 МБ, выходы (1, 6300, 117) и
  (1, 32, 80, 80).
* `yolo11n-pose.onnx` — **Hand**: Ultralytics YOLO11n-pose (17 ключевых точек
  человека, кисть = запястье), экспорт `yolo export format=onnx imgsz=320
  opset=12`, вход 320x320, выход 1x56x2100, 11 МБ (пик RSS ~15 МБ).
  Воспроизвести/обновить: `tools/export_pose.py`, подробности —
  docs/POSE_GUIDE.md.
* `classes.txt` — имена 80 классов COCO в порядке id (v1.6.12): если на Pi
  нет /home/pi/models/classes.txt, детектор читает этот файл — метки в
  оверлее и статусе не превращаются в «id0, id1…».

Контрольные суммы SHA-256 — в `SHA256SUMS` (`sha256sum -c models/SHA256SUMS`).

Детекционная модель `yolov5n.onnx` удалена в v1.6.10 вместе с режимами
YOLO (рамки) и YOLO Sem (карта классов).
