# Модели YOLO в архиве прошивки

Файлы поставляются вместе с кодом, чтобы робот не зависел от интернета
(setup.py копирует их в /home/pi/models/, если там их ещё нет).

* `yolov5n.onnx` — детекции, официальный релиз ultralytics/yolov5 **v7.0**
  (вход 640, 3.8 МБ).
  SHA-256: `04f0e55c26f58d17145b36045780fe1250d5bd2187543e11568e5141d05b3262`
* `yolov5n-seg.onnx` — сегментация (маски объектов), экспорт из официальных
  весов v7.0 (`yolov5n-seg.pt`) оригинальным экспортёром yolov5: opset 12,
  simplify, без динамических осей, вход 640, 8 МБ.
  SHA-256: `a7fac6c7aa489358a27011f81c38077683eeb5187a18e9b8d20e294d456bda36`

Обе модели проверены через cv2.dnn (чтение + инференс + постобработка):
пик RSS ~150 МБ (detect) / ~190 МБ (seg). Обновить модели или экспортировать
свою (вход 320, дообучение) — docs/YOLO_GUIDE.md и tools/fetch_yolo.py.
