# Управление памятью на RPi 3B+ (1 ГБ ОЗУ)

## Проблема

Стек PiCarPro (Flask + websockets + Picamera2 + OpenCV + драйверы I2C) в покое
занимает ~250–350 МБ. Добавление YOLO-инференса через cv2.dnn поднимает
потребление до ~700–900 МБ пиково — без swap процесс убивается OOM-killer'ом,
камера и веб-интерфейс падают.

## Решение — три слоя

### 1. Своп 2 ГБ (dphys-swapfile)

```bash
sudo bash tools/setup_swap.sh          # базовая настройка
sudo bash tools/setup_swap.sh --zram   # + zram (рекомендуется)
sudo bash tools/setup_swap.sh --size 4096   # если SD-карта большая
```

Скрипт делает:
* `CONF_SWAPSIZE=2048` в `/etc/dphys-swapfile` (по умолчанию было 100 МБ!);
* `vm.swappiness=80` — страницы выгружаются раньше, рост OOM отложен;
* `vm.vfs_cache_pressure=50` — меньше сбросов кэша inode/dentry;
* `vm.overcommit_memory=1` — разрешает резервы под буферы cv2;
* опционально zram (zstd, 50% RAM) — сжатый swap В ОЗУ.

### 2. ZRAM — зачем

Своп на SD-карте медленный (10–20 МБ/с, случайный доступ ещё хуже) и
изнашивает карту. ZRAM сжимает выгружаемые страницы в ОЗУ (zstd ~3–4x),
работает на порядки быстрее и бережёт SD. Приоритет zram выше — ядро сначала
использует его, SD-своп — последним рубежом.

### 3. Экономия ОЗУ приложением (уже сделано в коде)

| Мера | Эффект |
|---|---|
| YOLO через `cv2.dnn` (ONNX), без torch | −700…−800 МБ |
| Вход 320×320 вместо 640 | −75% вычислений, меньше буферов |
| `YOLO_FRAME_SKIP=3` | инференс ~в 3 раза реже |
| Ленивая загрузка модели (при включении режима) | фон не тратит память |
| Инференс в CVThread, не в MJPEG-потоке | стрим не блокируется |

## Дополнительные меры (на стороне ОС)

* Отключите рабочий стол: `sudo systemctl set-default multi-user.target`
* `gpu_mem=128` в `/boot/config.txt` (камере хватает; если камера не нужна — 16)
* Не запускайте одновременно YOLO-режим и голосовой Sherpa-NCNN
* Мониторинг: web-UI показывает `ram` в статусе; логи OOM: `dmesg | grep -i oom`

## Проверка под нагрузкой

```bash
free -h                      # до
python3 boot.py &            # сервер
# web-UI: включить режим YOLO на 5 минут
free -h && dmesg | tail      # после: без OOM-записей
swapon --show                # swap задействован умеренно
```
